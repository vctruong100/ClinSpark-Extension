# Privacy Policy for ClinSpark Extension

Effective date: July 28, 2026

ClinSpark Extension runs automation content scripts on the authorized ClinSpark environments used by CenExel.

## Data Collection

ClinSpark Extension does not collect, sell, transmit, or share user data with the developer or any third party.

## Local Browser Activity

The extension runs only on these ClinSpark domains:

- `https://cenexel.clinspark.com/*`
- `https://cenexeltest.clinspark.com/*`
- `https://cenexel-val.clinspark.com/*`

The automation scripts interact with ClinSpark pages in the user's browser to support authorized workflow automation. Any page data accessed by the scripts remains within the user's browser session and the ClinSpark application.

## Remote Code

The extension does not load or execute remote code. Updates are delivered through Chrome Web Store extension updates.

## Data Storage

The scripts may use browser page storage, such as local storage, to remember automation state and user interface preferences for ClinSpark workflows. This information is stored locally in the user's browser and is not sent to the developer.

## Contact

For questions about this privacy policy, contact the extension owner or administrator responsible for the Chrome Web Store listing.
